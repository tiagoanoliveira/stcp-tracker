01

Responsável pelo tratamento

O STCP Live é um projeto pessoal desenvolvido e mantido por Tiago Oliveira, residente em Portugal.

Este website não está associado a nenhuma empresa constituída. O responsável pelo tratamento dos dados pessoais dos utilizadores é o seu criador, a título individual, nos termos do Regulamento Geral sobre a Proteção de Dados (RGPD – Regulamento (UE) 2016/679).

02

Dados recolhidos

O STCP Live não recolhe dados pessoais identificáveis de forma direta. No entanto, como qualquer serviço web, alguns dados são processados automaticamente:

  • 📍
    Dados de localização (opcional) — apenas se autorizares o browser a aceder à tua localização. Estes dados são usados exclusivamente no teu dispositivo para centrar o mapa; nunca são enviados para servidores externos controlados pelo STCP Live.
  • ⚙️
    Preferências locais — filtros de linha e favoritos guardados no localStorage do teu browser. Estes dados ficam no teu dispositivo e não são transmitidos.
  • 📊
    Dados de utilização anonimizados — endereço IP (anonimizado), páginas visitadas, duração da sessão, tipo de dispositivo e browser, recolhidos através do Google Analytics.
  • 🌐
    Dados técnicos — informações de acesso padrão (logs do servidor de alojamento) como timestamp, endereço IP e recurso solicitado.
03

Finalidade e base legal

Os dados são tratados para as seguintes finalidades:

Finalidade Base legal (RGPD)
Funcionamento técnico do serviço Interesse legítimo (art. 6.º, n.º 1, al. f))
Análise de utilização e melhoria do serviço Consentimento (art. 6.º, n.º 1, al. a))
Localização geográfica do utilizador Consentimento explícito no browser
04

Cookies e tecnologias semelhantes

O STCP Live utiliza cookies de análise através do Google Analytics 4 para compreender como os utilizadores interagem com o site. Estes cookies são depositados apenas com o teu consentimento.

Cookie Fornecedor Duração Finalidade
_ga Google Analytics 2 anos Distinguir utilizadores únicos
_ga_* Google Analytics 2 anos Manter estado da sessão

Podes gerir ou eliminar os cookies a qualquer momento nas definições do teu browser. A recusa dos cookies de análise não afeta o funcionamento do serviço.

05

Partilha com terceiros

O STCP Live recorre aos seguintes serviços de terceiros, que podem processar dados dos utilizadores de acordo com as respetivas políticas de privacidade:

  • 📈
    Google Analytics — análise de tráfego anonimizado. Política de privacidade Google.
  • 🗺️
    OpenStreetMap / Leaflet — tiles do mapa servidos por provedores de tesselaturas. Política OSM.
  • 🚌
    API STCP — dados de localização de autocarros em tempo real fornecidos pela STCP, SA. O STCP Live não armazena nem retransmite estes dados além do necessário para a renderização do mapa.

Os dados nunca são vendidos, alugados ou partilhados para fins comerciais ou de marketing.

06

Retenção de dados

Os dados de análise anonimizados são retidos no Google Analytics pelo período padrão de 26 meses, após o qual são eliminados automaticamente. Os logs técnicos do servidor de alojamento são retidos por um período máximo de 30 dias.

As preferências guardadas localmente (localStorage) permanecem no teu dispositivo até que as elimines manualmente ou limpes os dados do browser.

07

Os teus direitos

Ao abrigo do RGPD, tens os seguintes direitos relativamente aos teus dados pessoais:

👁️
Acesso

Podes solicitar informação sobre os dados tratados.

✏️
Retificação

Podes corrigir dados inexatos.

🗑️
Apagamento

Podes solicitar a eliminação dos teus dados.

🚫
Oposição

Podes opor-te ao tratamento para fins de análise.

📦
Portabilidade

Podes receber os teus dados num formato estruturado.

⏸️
Limitação

Podes limitar o tratamento em determinadas circunstâncias.

Para exercer qualquer um destes direitos, contacta através do formulário disponível em tiagoanoliveira.pt/support. Tens também o direito de apresentar reclamação à Comissão Nacional de Proteção de Dados (CNPD) em cnpd.pt.

08

Segurança

O STCP Live é servido exclusivamente via HTTPS, garantindo a encriptação das comunicações entre o teu browser e o servidor. Como projeto pessoal sem tratamento de dados sensíveis, não são armazenadas bases de dados de utilizadores, passwords ou informação de pagamento.

09

Menores de idade

O STCP Live é um serviço de informação pública, acessível a utilizadores de qualquer idade. Não recolhemos intencionalmente dados pessoais de menores de 16 anos. Se tiveres conhecimento de que uma criança nos forneceu dados pessoais, pede-nos que os eliminemos através dos contactos indicados.

10

Alterações a esta política

Esta política pode ser atualizada ocasionalmente para refletir melhorias no serviço ou alterações legais. A data de "última atualização" no topo da página indica sempre a versão em vigor. Recomendamos que a consultes periodicamente.
